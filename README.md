# Invite All – הזמנת כולם לאירוע בפייסבוק

תוסף ל-Chrome שמסמן בלחיצה אחת את כל העוקבים בחלון ההזמנות של אירוע בפייסבוק. הוא גולל לבד כדי לטעון עוד אנשים, ועוצר כשהרשימה נגמרת, כשנגמרות ההזמנות (INVITES LEFT = 0) או כשלוחצים על "עצור".

## התקנה (פעם אחת)

1. פותחים את `chrome://extensions`
2. מדליקים את **Developer mode** (פינה ימנית למעלה)
3. לוחצים על **Load unpacked** ובוחרים את התיקייה הזאת:
   `/Users/tmanger/Documents/projects/invite-all-facebook-event-extension`
4. (מומלץ) לוחצים על סמל הפאזל בסרגל ומצמידים (📌) את Invite All

## שימוש

1. נכנסים לאירוע ולוחצים על **Invite**
2. בפינה השמאלית התחתונה מופיעה חלונית. לוחצים על **סמן את כולם**
   (אפשר גם דרך האייקון בסרגל, או עם קיצור המקלדת **Alt+Shift+I**)
3. כשזה נגמר, לוחצים בעצמך על **Send invites** בפייסבוק

בחלון של האייקון יש הגדרות: מהירות, זמן המתנה לטעינת עוד אנשים, מקסימום לסמן, ואם להציג את החלונית הצפה.

## למה התוסף הקודם נעלם, ואיך זה לא יקרה שוב

עדכון של Chrome לא מוחק תוסף שנטען ב-Load unpacked. בדרך כלל הוא נעלם מאחת הסיבות האלה:

| סיבה | מה עושים |
|---|---|
| התיקייה הועברה או נמחקה (למשל ב-Downloads או בתיקייה זמנית) | התוסף נמצא עכשיו בתיקיית פרויקט קבועה. **אל תזיז ואל תמחק אותה** |
| התקנה מקובץ `.crx` מחוץ לחנות (Chrome משבית את זה) | משתמשים רק ב-Load unpacked |
| טעינה דרך הדגל `--load-extension` (Chrome כבר לא תומך בזה) | כנ"ל |
| הקוד עצמו אבד | התיקייה מנוהלת ב-git. כדאי לדחוף אותה ל-GitHub פרטי לגיבוי |

אחרי שינוי בקוד, לוחצים על ⟳ (Reload) ליד התוסף ב-`chrome://extensions`. אין צורך לרענן את דף הפייסבוק.

## אם פייסבוק משנים משהו

כל הלוגיקה נמצאת ב-[content.js](content.js):
- `findInviteDialog`: מחפש `[role="dialog"]` עם checkboxes ומילה כמו invite או "הזמנ"
- `LEFT_PATTERNS`: זיהוי "INVITES LEFT" באנגלית ובעברית
- `getScrollContainer`: האלמנט שגוללים בו כדי לטעון עוד אנשים

## קבצים

- `manifest.json`: הגדרות התוסף (Manifest V3)
- `content.js`: רץ בדף פייסבוק, מסמן את האנשים ומציג את החלונית הצפה
- `popup.html/.css/.js`: החלון של האייקון בסרגל וההגדרות
- `background.js`: קיצור המקלדת
- `scripts/make_icons.py`: יוצר מחדש את האייקונים (`python3 scripts/make_icons.py`)
